# Tiger UI theme visual prompts

The following prompts were used with the three supplied club photographs as visual references only. The generated artwork is original and does not copy the photographs' logos, text, watermarks, people, or composition.

## UI 02 — Winged Tiger / 如虎添翼

```text
Use case: stylized-concept
Asset type: responsive website hero background for Tiger Badminton Club theme 02, 如虎添翼
Input images: Images 1–3 are visual references only for the real badminton club atmosphere, especially the saturated yellow pennants, black Chinese brush calligraphy, emerald courts, cobalt blue walls, and industrial hall energy. Do not copy any existing logo, text, watermark, people, or photo composition.
Primary request: create an original Chinese ink-wash illustration of a powerful tiger in motion, carrying a badminton racket naturally in its mouth, with two elegant expressive wings, embodying the idiom 如虎添翼. The pose must be anatomically coherent and graceful, with the racket clearly recognizable and not fused into the tiger.
Scene/backdrop: warm aged rice-paper field with sweeping black and amber brush strokes, subtle yellow silk-banner glow, restrained hints of emerald court-line geometry far in the background.
Style/medium: premium contemporary shuimo ink painting blended with screen-print poster texture; sophisticated, artistic, minimal rather than cartoonish.
Composition/framing: wide 3:2 landscape; tiger and wings concentrated on the right 55% of the canvas; generous quiet negative space on the left for website headline; subject fully inside frame with breathing room; works when center-cropped on mobile.
Lighting/mood: bold, spirited, ceremonial, refined.
Color palette: parchment cream, carbon black, imperial yellow, burnt amber, tiny muted emerald accents.
Constraints: no text, no Chinese characters, no logos, no watermark, no border, no extra animals, exactly one tiger, exactly two wings, exactly one badminton racket, no shuttlecock, no blue dominant background. Avoid photorealism, 3D render, childish mascot style, malformed paws, extra limbs, fused objects, clipped wings.
```

## UI 03 — Yellow Sport / 黄黑竞技

```text
Use case: stylized-concept
Asset type: responsive website hero background for Tiger Badminton Club theme 03, modern sport fashion
Input images: Images 1–3 are visual references only for the club's electric yellow pennants, black graphics, industrial structure, green courts, and competitive badminton energy. Do not copy any existing logo, text, watermark, person, or photo composition.
Primary request: create an original minimal sport-fashion tiger visual: a fast, elegant tiger formed from bold geometric black shapes, disciplined contour lines, and a few yellow speed streaks, paired with one clearly recognizable badminton racket as an integrated but separate sporting element. Strong silhouette suitable for a premium contemporary athletic brand.
Scene/backdrop: saturated warm yellow field with subtle tonal blocks and abstract badminton court lines; no realistic venue.
Style/medium: flat editorial sports poster, Swiss/Japanese graphic design influence, screen-print texture, sharp and minimal, premium apparel campaign feel; not a mascot logo and not cartoonish.
Composition/framing: wide 3:2 landscape; tiger action silhouette on the right 58%; generous clean negative space on the left for website headline; balanced when center-cropped on mobile; all elements fully inside canvas.
Lighting/mood: kinetic, confident, modern, clean.
Color palette: dominant court yellow, rich matte black, off-white, tiny restrained emerald accent only.
Constraints: no text, no Chinese characters, no logos, no watermark, no border, exactly one tiger and exactly one badminton racket, no wings, no shuttlecock, no 3D, no gradients that reduce legibility, no detailed background, no extra limbs, no malformed anatomy, no fused racket, no childish sports mascot.
```
